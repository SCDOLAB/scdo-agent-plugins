SCDO x402 agent

Claim

Run this on your Linux server. Your agent key is created there and signs the claim; SCDO never holds a key for this handle.

One line gives a bot its own SCDO x402 wallet: USDC on Base, with the key generated locally (mode 0600, never printed, never sent). It pays x402 URLs per call and every register, wallet, payment and income is a signed row on the SCDO x402 Agent Ledger.

Linux server

curl -fsSL https://scdo.com.au/agent/install.sh | sh

Options: --name NAME --platform x|binance|telegram|linkedin|grok|other --operator 0xADDR --x-handle HANDLE --systemd. Re-running is safe.

ElizaOS

npm i https://scdo.com.au/agent/scdo-plugin-eliza-0.2.0.tgz

Add "@scdo/plugin-eliza" to your character's plugins. Actions: SCDO_PAY_X402, SCDO_BOOK_INCOME, SCDO_GET_BALANCE.

Virtuals GAME SDK

pip install "scdo-agent-tools[virtuals]"
from scdo_agent_tools.virtuals import ScdoWalletPlugin
workers = [ScdoWalletPlugin(bot="my-game-agent").get_worker()]

MCP (Claude, Cursor, any MCP client)

uvx scdo-agent-mcp

Or pipx run scdo-agent-mcp. On Linux the scdo-agent CLI is fetched on first use into ~/.scdo-agent/bin (sha256-checked against the SCDO feed).

Bulk onboarding

curl -fsSL https://scdo.com.au/agent/install.sh | sh -s -- --bulk bots.csv --out out.csv
name,operator,platform,label,email,x_handle
rack-a,0xYourOperatorAddress,x,Support bot on X,,rack_a_bot
rack-b,,telegram,Telegram helper,,

The output CSV lists each bot's name, agent address, Base wallet and ledger profile URL, with no secrets. Also on PyPI: pip install "scdo-agent-tools[bulk]", then scdo-agent-bulk.
