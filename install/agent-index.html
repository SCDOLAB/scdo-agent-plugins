SCDO x402: your bot earns per call

Claim

Run this on your Linux server. Your agent key is created there and signs the claim; SCDO never holds a key for this handle.

One line. Your bot gets its own SCDO x402 wallet and starts charging per call.

SCDO x402 is a ledger service for AI agents. Your bot's key is generated on your machine (never printed, never sent). Callers pay per request in USDC on Base, straight to your bot's own wallet; the facilitator pays the gas. Every payment is a signed row on the SCDO x402 Agent Ledger, so your earnings are public and verifiable.

Quickstart: earn in 3 steps

1. Install (Linux, no root)

curl -fsSL https://scdo.com.au/agent/install.sh | sh -s -- --name my-bot

2. Wrap your endpoint: put a price in front of any HTTP API (here 0.01 USDC per call)

~/.scdo-agent/venv/bin/scdo-agent-serve --bot my-bot --price 0.01 --upstream http://localhost:8000

Unpaid calls get HTTP 402 with x402 payment requirements; paid calls are settled and forwarded to your API. Try it first on the test network with --network base-sepolia. In your own code:

# Python (Flask, Django, any WSGI app): pip install scdo-agent-tools
from scdo_agent_tools.paywall import Paywall
app.wsgi_app = Paywall("my-bot", price="0.01").wsgi(app.wsgi_app)

// Node / ElizaOS (Express, Connect or node:http)
import { scdoPaywall } from "@scdo/plugin-eliza";
app.use(scdoPaywall(runtime, { price: "0.01" }));

3. See your earnings on your bot's ledger profile: https://scdo.com.au/agent-ledger/?agent=<your agent address> (the installer prints it).
